# MindGen AI

Aplikasi mind mapping interaktif berbasis React. Pengguna memasukkan topik/prompt, kemudian aplikasi membuat struktur mind map yang dapat dipindahkan, dihubungkan, disimpan, dan diekspor.

## Teknologi
- React
- Vite
- React Flow
- Tailwind-inspired custom CSS
- Lucide React
- html-to-image
- LocalStorage

## Instalasi

Pastikan Node.js sudah terpasang.

```bash
npm install
npm run dev
```

Buka alamat yang muncul di terminal, biasanya `http://localhost:5173`.

## Fitur
- Prompt/topic generator
- Template topik
- Interactive canvas
- Drag node
- Connect node
- Tambah node
- Simpan ke browser
- Reset canvas
- Export PNG
- MiniMap dan zoom controls

## Catatan
Versi ini menggunakan generator lokal berbasis template/kata kunci, sehingga tidak membutuhkan API AI atau API key. Struktur generator dapat dikembangkan menjadi AI sungguhan dengan menghubungkan backend/API model bahasa.
